適用範圍與聯絡

本政策適用於 Timo、其小工具與本官網。開發者公開識別為 arvin-manager，隱私及支援聯絡：anarvin212@gmail.com。第三方另依其政策處理資料。

你提供的內容

計畫、日期、備註、子計畫、專注紀錄、備忘錄、倒數日、偏好與所選照片通常存於裝置。照片經本機壓縮及中繼資料清理，App 不主動掃描整個相簿。你主動匯出或上傳的備份可包含內容與照片，請避免填入不必要的敏感資訊。

登入與手動雲端備份

本機功能不需帳號。Google／Apple 與 Firebase Authentication 會處理登入憑證、識別碼、獲授權的姓名、電子郵件及技術資訊；Timo 不取得平台密碼。僅在你主動上傳時，內容快照、版本、時間及筆數才傳至 Google Cloud Firestore。備份依帳號隔離，並非自動同步、合併或端對端加密。登出不會刪除備份。

自選的使用分析

「幫助改善團團」預設關閉。開啟後 Firebase Analytics 接收頁面、登入方式、象限、功能、計時模式與分鐘、備份筆數及裝置、App 實例和網路技術資訊。不傳送計畫標題、正文、備註、照片、電子郵件或帳號 ID；不設定分析使用者 ID，停用自動頁面回報及 IDFA／IDFV 收集。事件可連結同一安裝實例，Google 可能以遮罩 IP 推算大致地區，無需 GPS。登入及備份仍可能處理必要診斷。可在「設定 → 資料與隱私」撤回並重設本機分析狀態；已傳送資料不會因此自動刪除，可另行聯絡。

廣告與隱私選擇

首次 72 小時體驗與有效訂閱期間不請求廣告。其餘時間首頁、統計可顯示 AdMob 橫幅，儲存計畫、離開專注結果或處理逾期後返回首頁可能限頻顯示插頁；編輯及計時中不顯示。Google UMP 先處理適用地區的選擇，請求為非個人化且不申請跨 App 追蹤授權。非個人化廣告仍可能處理 IP、裝置或廣告識別碼、大致地區、診斷、曝光和互動，用於投放、衡量、限頻與防詐。實際依 Google SDK 版本及揭露為準。適用時在「資料與隱私 → 廣告隱私選項」管理，與分析開關分開。

訂閱與體驗紀錄

Apple StoreKit 處理訂閱、付款及退款，Timo 以 Apple 驗證交易判斷權益，不接收卡號，也不傳至自建購買伺服器。鑰匙圈儲存首次使用與最近觀察時間，用來計算一次 72 小時體驗及減少回撥時間重領；不納入匯出或雲端備份。清空內容不重設體驗，一般重新安裝仍會保留，並非跨裝置帳號試用。

權限、備忘錄鎖與螢幕

啟用本機提醒才申請通知；照片及分享使用系統介面，拍攝備忘錄照片才申請相機。核心功能不需通訊錄、麥克風或精確位置。檔案僅用於你選擇的匯入匯出。數字密碼免費，會員／體驗可用手勢及 Face ID／Touch ID。加鹽衍生憑證存於本機鑰匙圈，不納入備份；iOS 只回傳驗證結果，不提供原始臉部、指紋或模板。存取鎖不加密資料庫或備份。小工具經本機 App Group 顯示標題、摘要、日期、專注狀態及照片；啟用備忘錄鎖後隱藏摘要。即時動態可在鎖定畫面及動態島顯示標題與時間，請留意螢幕可見性。

節假日與網路

選定地區的節假日可由 Firestore 公開快取和 Nager.Date 取得，請求包含國家、分區與年份，服務商可能收到 IP 和網路日誌；不使用 GPS，也不傳送計畫或備忘錄。優先使用本機副本，資料可能不完整。

官網與支援郵件

官網為 GitHub Pages 靜態頁，不嵌入廣告、分析腳本或追蹤 Cookie。GitHub 仍可能處理 IP、瀏覽器、存取與安全日誌。外部網站與郵件商另有政策。支援郵件的地址、問題與附件用於回覆、排查和適用義務。

目的、依據與服務商

本機處理執行你的操作；登入及備份提供你請求的服務；分析依可撤回選擇，廣告依地區規則，安全、防濫用及必要支援用於合法權益和法定義務。不出售計畫、備忘錄或備份內容予廣告商，也不以其定向。服務商包含 Google、Apple、GitHub、Nager.Date 和郵件商；相關功能使用時處理必要資料，法律要求或保護權利時可作必要揭露。

保存與刪除

本機內容保留至刪除、清空或解除安裝，系統副本依 iOS 設定。雲端通常保留目前與上一版，直到替換或刪除帳號；未完成上傳於清理或刪除時移除。成功刪除會移除 Firebase 帳號及雲端內容，可能保留與舊識別碼連結的最小刪除標記，防止有效舊權杖重建資料；不含正文或聯絡資料。分析、廣告、日誌和復原副本依服務商設定及法律保存，不保證即時移除所有副本。支援信件保留至問題及必要後續處理完，可要求刪除；匯出及轉交他人的副本需自行刪除。

選擇與權利

你可編輯、刪除、匯出、停用分析、調整廣告、撤銷權限。「設定 → 登入與帳號 → 刪除帳號」需驗證身分，刪除所有雲端備份但保留本機及匯出檔。可電郵要求存取、更正、刪除、限制、資料副本、撤回同意、反對或申訴；我們依適用期限回應，必要時驗證身分。地區法律可提供監管申訴、出售／分享退出等額外權利，不因行使權利而歧視。

跨境與安全

服務商可能在所在地以外處理資料，儲存位置、傳輸機制及保障依設定、合約和法律。使用 HTTPS、帳號存取控制及必要驗證；任何系統皆非絕對安全，也不聲稱所有內容皆端對端加密。請保護帳號和備份。

兒童

Timo 並非專為 13 歲以下兒童提供，也不主動索取年齡或兒童資料。需監護人同意的地區，使用相關線上服務前應取得同意。如發現未適當授權處理兒童資料，請聯絡以便調查、刪除或採取必要措施。

政策更新

更新時標註日期；對資料用途或權利有重大影響時，在 App 或官網提示，依法需要時重新取得同意。
