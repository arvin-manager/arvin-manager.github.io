适用范围与联系

本政策说明「团团专注 Timo」App、其桌面小组件及本官网如何处理信息。开发者公开标识为 arvin-manager，隐私及支持联系邮箱为 anarvin212@gmail.com。第三方平台的独立处理也受其自身政策约束。

你主动提供的信息

计划标题、日期、备注、子计划、专注记录、备忘录、倒数日、偏好及所选背景照片通常保存在设备内。照片仅在你选择后用于背景和分享，App 不主动扫描整库；照片背景会做本机压缩和元数据清理。手动导出及手动云备份可能包含这些内容和照片。请避免在内容中填写不必要的敏感信息。

登录与手动云备份

你可以不登录使用本机功能。选择 Google 或 Apple 登录时，相应平台和 Firebase Authentication 处理身份凭据、用户标识，以及平台授权提供的姓名、邮箱和登录技术信息，以认证和隔离你的备份。App 不获取平台密码。

仅在你主动上传云备份时，内容快照和版本、时间、条数等元数据会发送至 Google Cloud Firestore。云备份是手动快照，不自动合并设备修改。后台按账号隔离访问；这不是端到端加密服务。退出登录保留账号和云备份。

可选的使用分析

「帮助改善团团」默认关闭。你开启后，Firebase Analytics 接收页面浏览、登录方式、四象限、功能使用、计时模式与分钟、备份条数等允许的事件，以及 SDK 运行所需的应用、设备、实例标识和网络等技术信息。App 不把计划标题、正文、备注、照片、邮箱或账号 ID 放入分析事件；未设置分析用户 ID，并关闭自动页面上报及 IDFA／IDFV 采集。

你可以在「设置 → 数据与隐私」撤回，停止后续采集并重置本机 Analytics 状态。撤回不会自动追溯删除已发送且由服务商保留的数据；需要进一步处理时请联系我们。

广告与隐私选择

设置页可在正式启用广告后展示 Google AdMob 横幅，不在专注流程插入广告。广告功能是否可用取决于发行版本和配置；未启用广告时不请求正式广告。请求前使用 Google UMP 处理适用地区的同意选择，请求为非个性化广告，不申请跨 App 跟踪授权。

非个性化不代表不处理数据。Google 广告 SDK 仍可能处理 IP 地址、设备或广告标识符、粗略位置推断、诊断及广告展示、互动信息，用于投放、衡量、限制频次及防作弊。SDK 的实际处理以对应版本和 Google 披露为准。适用时可在「数据与隐私 → 广告隐私选项」管理。分析开关不控制广告选择。

权限、提醒与屏幕显示

通知仅在你选择启用后申请，用于本地计划、专注和倒数日提醒。照片选择和分享通过系统界面进行；发送到哪里由你决定。文件访问用于你主动选择的备份导入与导出。App 不为核心功能请求通讯录、麦克风或精确定位。

桌面小组件通过本机 App Group 获取计划标题、备忘录摘要、日期、专注状态及选定照片等显示数据；实时活动可能在锁屏和灵动岛显示专注标题和时间。请自行选择组件与系统显示设置，避免他人从屏幕看到私人内容。

节假日与网络请求

为获取选定地区和年份的节假日，App 可请求 Google Firestore 的公开日历缓存及 Nager.Date。请求包含国家／地区、州／地区和年份，服务方可收到 IP 地址及网络技术日志；这不是 GPS 定位，也不会上传你的计划或备忘录。优先使用本机已有副本，网络或来源不可用时可能只能显示已有数据。

官网托管与支持邮件

官网为 GitHub Pages 上的静态页面，本页面不嵌入广告、分析脚本或追踪 Cookie。GitHub 仍可按其政策处理 IP 地址、浏览器信息、访问及安全日志。外部链接、邮箱服务与 GitHub 各自有独立政策。你联系支持时，我们处理你主动发送的邮箱、问题和附件，只用于回复、排查及履行适用义务。

处理目的、依据与第三方

本机功能用于执行你的操作；身份和备份用于提供你请求的服务；使用分析基于你的可撤回选择；广告选择依适用地区规则处理。安全、防滥用及必要支持用于维护服务和合法权益；依法需要时履行法定义务。我们不将你的计划、备忘录或备份内容出售给广告商，也不将这些内容用于广告定向。

服务商包括 Google（Firebase Auth、Firestore、Analytics、AdMob／UMP）、Apple（登录及系统能力）、GitHub（官网）、Nager.Date（公开日历）及邮件服务商。第三方只因相关功能被调用而收到必要信息；依法要求或保护权利时，也可能作必要披露。

存储期限、删除与备份

本机内容在你删除、清空或卸载前保存在设备，系统副本也受 iOS 设置影响。云备份通常保留当前和上一版本，直到更新替换或注销账号；未完成上传的片段在清理或注销时移除。成功注销会删除 Firebase 账号及云内容；为防止尚未失效的登录令牌重建内容，服务器可保留与原账号标识关联的最小删除标记，不含备份正文或联系方式。

分析、广告、安全日志与服务商灾备的期限依后台设置、服务商政策和法定义务，不承诺立即从所有系统副本清除。支持邮件保留至问题处理及必要后续结束；可请求删除，无需继续保留时处理。你导出的文件和发给第三方的副本需自行删除。

你的选择与权利

你可以在 App 内修改或删除内容、导出文件、关闭分析、调整广告选择、撤回系统权限及注销账号。「设置 → 登录与账号 → 注销团团账号」需身份验证，会删除全部云备份，但保留本机内容与导出文件；清空本机数据是独立操作。

你也可通过上述邮箱请求访问、更正、删除、限制处理、数据副本、撤回同意，或提出异议与投诉。我们会在适用法律规定的期限内处理，并可能先验证身份。适用地区的法律可能赋予额外权利，包括向监管机构投诉及适用的出售／共享退出权；不会因依法行使权利而歧视你。

国际处理与安全

使用 Google、Apple、GitHub 等服务时，信息可能在你所在地区以外处理。实际存储地区、跨境机制及服务商保障以服务配置、协议和适用法律为准。我们使用平台 HTTPS、账号访问控制和必要的数据校验保护信息；无法保证任何系统绝对安全，也不声称所有内容采用端到端加密。请妥善保管登录账号和导出文件。

未成年人

本产品不是面向 13 岁以下儿童的专门服务，也不主动要求填写年龄或收集儿童信息。如你所在地要求监护人同意，应在取得适当同意后使用相关在线服务。若发现未经适当授权处理了儿童个人信息，请联系上述邮箱，我们会核实并采取删除或其他必要措施。

政策更新

我们会在本页更新政策并注明生效日期。对数据用途或你的权利有重大影响的变更，将通过 App 或官网作适当提示，并在适用法律要求时重新征求同意。
