النطاق والتواصل

تشمل هذه السياسة Timo وأدواته وهذا الموقع. معرّف المطوّر العام arvin-manager، والتواصل عبر anarvin212@gmail.com. تخضع المعالجة المستقلة لدى الأطراف الأخرى لسياساتها أيضًا.

المحتوى الذي تقدمه

تُحفظ الخطط والتواريخ والملاحظات والمهام الفرعية وسجلات التركيز والمذكرات والمناسبات والتفضيلات والصور المختارة عادة على جهازك. تُضغط الصور وتُنظف بياناتها الوصفية محليًا، ولا يفحص التطبيق مكتبة الصور كاملة. قد تشمل الصادرات والنسخ السحابية اليدوية هذه البيانات؛ تجنب المعلومات الحساسة غير الضرورية.

الدخول والنسخ اليدوي

لا تحتاج الميزات المحلية إلى حساب. تعالج Google／Apple وFirebase Authentication بيانات الاعتماد والمعرّفات والاسم والبريد المصرح بهما والمعلومات التقنية. لا يحصل Timo على كلمة مرور المنصة. عند بدء الرفع فقط تُرسل لقطة المحتوى والإصدار والوقت وعدد السجلات إلى Firestore. يُفصل الوصول حسب الحساب؛ لا تتوفر مزامنة أو دمج تلقائي ولا تشفير بين الطرفين. تسجيل الخروج لا يحذف الحساب أو النسخ.

التحليلات الاختيارية

معطلة افتراضيًا. عند تفعيلها يتلقى Firebase Analytics الشاشات وطريقة الدخول والأرباع واستخدام الميزات ونوع المؤقت ودقائقه وأعداد النسخ، وبيانات التطبيق والجهاز ومعرّف النسخة والشبكة. لا تتضمن الأحداث العناوين أو النصوص أو الملاحظات أو الصور أو البريد أو معرّف الحساب. لا نحدد معرّف مستخدم للتحليل ونعطل تقارير الشاشة التلقائية وجمع IDFA／IDFV. قد ترتبط الأحداث بالتثبيت نفسه وقد تستنتج Google منطقة تقريبية من عنوان IP مقنّع، بلا GPS. قد تعالج خدمات الدخول والنسخ تشخيصات لازمة. اسحب اختيارك من الإعدادات ← البيانات والخصوصية لإيقاف الجمع وإعادة ضبط التحليل المحلي؛ لا يحذف ذلك تلقائيًا البيانات المرسلة سابقًا. تواصل لطلبات إضافية.

الإعلانات والخيارات

لا نطلب إعلانات خلال أول 72 ساعة أو مع اشتراك نشط. بعدها قد تظهر لافتات AdMob في الرئيسية والإحصاءات وإعلانات بينية محدودة بعد حفظ خطة أو إغلاق نتيجة التركيز أو معالجة المتأخرات والعودة للرئيسية؛ لا أثناء التحرير أو التوقيت. تدير Google UMP الخيارات الإقليمية قبل الطلبات غير المخصصة، ولا نطلب إذن تتبع عبر التطبيقات. حتى الإعلانات غير المخصصة قد تعالج IP ومعرّفات الجهاز أو الإعلان والمنطقة التقريبية والتشخيصات والمشاهدات والتفاعلات للتوصيل والقياس وتحديد التكرار ومنع الاحتيال، بحسب إصدار SDK وإفصاحات Google. خيارات خصوصية الإعلان منفصلة عن مفتاح التحليل حيث تنطبق.

الشراء والتجربة

تدير Apple StoreKit الاشتراكات والدفع والاسترداد. نعتمد معاملات Apple المتحققة ولا نتلقى بيانات البطاقات أو نرسل المعاملات إلى خادم شراء خاص. تحفظ سلسلة المفاتيح وقت أول استخدام وآخر وقت مرصود لحساب تجربة واحدة من 72 ساعة وتقليل التلاعب بالساعة. لا تُضمّن هذه الأوقات في النسخ، ولا يعيد مسح المحتوى التجربة، وعادة تبقى بعد إعادة التثبيت. التجربة لكل جهاز وليست عرض حساب متعدد الأجهزة.

الأذونات والشاشة

نطلب الإشعارات للتذكيرات التي تختارها؛ تستخدم الصور والمشاركة واجهات النظام، والكاميرا عند تصوير مذكرة فقط. لا تحتاج الوظائف الأساسية إلى جهات اتصال أو ميكروفون أو موقع دقيق. الملفات للنسخ التي تختارها. الرمز الرقمي مجاني، والنمط وFace ID／Touch ID المتوافقان مع Plus أو التجربة. تُحفظ مشتقات الاعتماد المملحة في سلسلة المفاتيح المحلية بلا نسخ احتياطي. يعيد iOS نتيجة المصادقة فقط، لا الوجه أو البصمة أو القوالب. القفل لا يشفّر قاعدة البيانات أو الصادرات. تعرض الأدوات العناوين والمقتطفات والتواريخ والحالة والصور عبر App Group محلي؛ تُخفى مقتطفات المذكرات عند القفل. قد تعرض الأنشطة الحية عنوان التركيز والوقت على شاشة القفل وDynamic Island؛ انتبه لمن يرى الشاشة.

العطلات والشبكة

قد نرسل البلد والمنطقة الفرعية والسنة المختارة إلى ذاكرة Firestore العامة أو Nager.Date. قد يتلقى المزودون IP وسجلات تقنية، لا خططك أو مذكراتك أو GPS. نفضّل النسخ المحلية؛ قد تكون التغطية ناقصة.

الموقع والدعم

الموقع ملفات ثابتة على GitHub Pages بلا إعلانات أو نصوص تحليل أو ملفات تتبع مدمجة. قد تعالج GitHub عناوين IP والمتصفح وسجلات الدخول والأمان. للمواقع المرتبطة وخدمات البريد سياسات مستقلة. نستخدم عنوان البريد والرسالة والمرفقات للرد والتحقيق والالتزامات السارية.

الأغراض والمزودون

المعالجة المحلية تنفذ أوامرك؛ الدخول والنسخ يقدمان الخدمة المطلوبة؛ التحليل باختيار قابل للسحب والإعلان وفق القواعد الإقليمية. الأمان ومنع الإساءة والدعم اللازم يحمي المصالح المشروعة وينفذ الالتزامات القانونية. لا نبيع محتوى خططك أو مذكراتك أو نسخك للمعلنين ولا نستهدف به الإعلانات. تتلقى Google وApple وGitHub وNager.Date ومزودو البريد ما يلزم عند استخدام وظائفهم. قد يتم الإفصاح الضروري بموجب القانون أو لحماية الحقوق.

الاحتفاظ والحذف

يبقى المحتوى المحلي حتى تحذفه أو تمسحه أو تزيل التطبيق؛ نسخ النظام تعتمد على iOS. تحتفظ السحابة عادة بالإصدار الحالي والسابق حتى الاستبدال أو حذف الحساب، وتُزال عمليات الرفع غير المكتملة بالتنظيف. قد يبقى مؤشر حذف أدنى مرتبط بالمعرّف السابق لمنع رموز صالحة من إعادة إنشاء المحتوى، بلا نص أو بيانات اتصال. التحليل والإعلانات والسجلات ونسخ الاستعادة تتبع إعدادات المزود وسياساته والقانون؛ لا نضمن حذف كل نسخة فورًا. يبقى بريد الدعم حتى الحل والمتابعة الضرورية ويمكن طلب حذفه إن لم يعد مطلوبًا. احذف صادراتك والنسخ المرسلة بنفسك.

حقوقك وخياراتك

يمكنك التحرير والحذف والتصدير وإيقاف التحليل وتغيير الإعلان وسحب الأذونات. حذف الحساب من الإعدادات يتطلب إثبات الهوية ويحذف السحابة كلها مع بقاء المحلي والصادرات. اطلب بالبريد الوصول أو التصحيح أو الحذف أو التقييد أو نسخة أو سحب الموافقة أو الاعتراض أو الشكوى. نرد ضمن المهل القانونية وقد نتحقق من الهوية. نحترم الحقوق الإقليمية الإضافية مثل الشكوى للجهة الرقابية وخيارات رفض البيع／المشاركة حيث تنطبق، بلا تمييز.

المعالجة الدولية والأمان

قد يعالج المزودون خارج منطقتك. المواقع وآليات النقل والضمانات تعتمد على الإعدادات والعقود والقوانين. نستخدم HTTPS والتحكم حسب الحساب والتحقق، بلا ضمان أمان مطلق أو تشفير كل المحتوى بين الطرفين. احمِ الحسابات والنسخ المصدرة.

الأطفال
