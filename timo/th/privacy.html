ขอบเขตและติดต่อ

นโยบายนี้ครอบคลุม Timo วิดเจ็ต และเว็บไซต์ ผู้พัฒนามีชื่อสาธารณะ arvin-manager ติดต่อ anarvin212@gmail.com บุคคลที่สามมีนโยบายสำหรับการประมวลผลของตนเอง

เนื้อหาที่ให้

แผน วันที่ หมายเหตุ แผนย่อย ประวัติโฟกัส บันทึก วันสำคัญ การตั้งค่า และภาพที่เลือกมักเก็บในเครื่อง ภาพถูกบีบอัดและล้างข้อมูลกำกับในเครื่อง แอปไม่สแกนคลังภาพทั้งหมด ไฟล์ส่งออกและสำรองคลาวด์ที่คุณสั่งอาจมีเนื้อหาและภาพ จึงควรหลีกเลี่ยงข้อมูลอ่อนไหวที่ไม่จำเป็น

สำรองข้อมูลบนคลาวด์

ฟังก์ชันในเครื่องไม่ต้องมีบัญชี Google หรือ Apple และ Firebase Authentication ประมวลผลตัวระบุ ชื่อ อีเมล และข้อมูลเข้าสู่ระบบที่คุณอนุญาต Timo ไม่ได้รับรหัสผ่านของผู้ให้บริการ การสำรองด้วยตนเองหรือการสำรองอัตโนมัติที่คุณเปิดด้วย Plus จะส่งเนื้อหา เวอร์ชัน เวลา และจำนวนรายการไปยังพื้นที่ส่วนตัวของบัญชีใน Firestore เก็บได้สูงสุดห้าเวอร์ชันที่สมบูรณ์ ไม่รวมการแก้ไขข้ามอุปกรณ์และไม่ใช่การเข้ารหัสจากต้นทางถึงปลายทาง การออกจากระบบยังคงข้อมูลในเครื่องและข้อมูลสำรองคลาวด์ไว้

การวิเคราะห์ตามเลือก

ปิดเป็นค่าเริ่มต้น หากเปิด Firebase Analytics รับหน้าจอ วิธีเข้าสู่ระบบ ช่องแผน การใช้ฟังก์ชัน โหมดและนาทีจับเวลา จำนวนสำรอง และข้อมูลแอป เครื่อง ตัวระบุอินสแตนซ์กับเครือข่าย ไม่ส่งชื่อแผน ข้อความ หมายเหตุ ภาพ อีเมล หรือ ID บัญชีในเหตุการณ์ ไม่กำหนด ID ผู้ใช้วิเคราะห์ และปิดรายงานหน้าจออัตโนมัติกับ IDFA／IDFV เหตุการณ์อาจเชื่อมกับการติดตั้งเดียว Google อาจอนุมานพื้นที่คร่าว ๆ จาก IP ที่ปกปิด โดยไม่ขอ GPS บริการเข้าสู่ระบบและสำรองอาจประมวลผลวินิจฉัยที่จำเป็น ถอนตัวเลือกที่การตั้งค่า → ข้อมูลและความเป็นส่วนตัวเพื่อหยุดเก็บและรีเซ็ตสถานะในเครื่อง ไม่ได้ลบข้อมูลที่ส่งแล้วโดยอัตโนมัติ ติดต่อเพื่อขอเพิ่มเติม

หากเปิดการวิเคราะห์แบบเลือกได้ Timo จะบันทึกสินค้าและผลการซื้อ จำนวนการแสดงและรายได้โฆษณาโดยประมาณ รวมถึงจำนวนการใช้งานและสำรองข้อมูล ปิดไว้โดยค่าเริ่มต้นและยกเลิกได้ในการตั้งค่า

โฆษณาและตัวเลือก

ไม่ขอโฆษณาในช่วงทดลอง 72 ชั่วโมงหรือสมาชิกที่ยังมีผล นอกนั้นอาจแสดงแบนเนอร์ AdMob หน้าแรกและสถิติ และโฆษณาคั่นจำกัดความถี่หลังบันทึกแผน ปิดผลโฟกัส หรือจัดการแผนเกินกำหนดแล้วกลับหน้าหลัก ไม่แสดงขณะจับเวลาหรือแก้ไข Google UMP จัดการตัวเลือกตามพื้นที่ก่อนคำขอแบบไม่ปรับเฉพาะบุคคล และไม่ขอติดตามข้ามแอป แต่ยังอาจประมวลผล IP ตัวระบุเครื่องหรือโฆษณา พื้นที่คร่าว ๆ วินิจฉัย การแสดงผลและโต้ตอบ เพื่อส่ง วัด จำกัดความถี่ และป้องกันทุจริต ตาม SDK และคำเปิดเผยของ Google ตัวเลือกโฆษณาที่เกี่ยวข้องแยกจากสวิตช์วิเคราะห์

ดูโฆษณาเพื่อปลดล็อกหนึ่งธีมเป็นเวลา 24 ชั่วโมง การปิดเร็วหรือการเล่นล้มเหลวจะไม่ได้รับรางวัล

การซื้อและทดลอง

Apple StoreKit จัดการสมาชิก ชำระเงิน และคืนเงิน Timo ใช้ธุรกรรมที่ Apple ตรวจสอบ ไม่รับข้อมูลบัตรหรือส่งธุรกรรมไปเซิร์ฟเวอร์ซื้อของตนเอง Keychain เก็บเวลาใช้ครั้งแรกและเวลาล่าสุดที่พบ เพื่อทดลองครั้งเดียว 72 ชั่วโมงและลดการย้อนนาฬิกา ไม่รวมในไฟล์หรือคลาวด์ การล้างเนื้อหาไม่เริ่มทดลองใหม่และมักอยู่หลังติดตั้งใหม่ เป็นการทดลองตามเครื่อง ไม่ใช่หลายเครื่องต่อบัญชี

สิทธิ์และหน้าจอ

ขอแจ้งเตือนเมื่อเลือกเตือนในเครื่อง ภาพและแชร์ใช้ระบบ กล้องขอเฉพาะถ่ายภาพบันทึก ฟังก์ชันหลักไม่ขอรายชื่อ ไมโครโฟน หรือตำแหน่งละเอียด ไฟล์ใช้กับสำรองที่เลือก PIN ตัวเลขฟรี ส่วนลายเส้นและ Face ID／Touch ID ที่รองรับใช้ Plus หรือทดลอง ค่าที่ได้จากรหัสพร้อม salt อยู่ใน Keychain ในเครื่อง ไม่เข้าสำรอง iOS ส่งเพียงผลยืนยัน ไม่ส่งใบหน้า ลายนิ้วมือ หรือแม่แบบ ล็อกไม่เข้ารหัสฐานข้อมูลหรือไฟล์สำรอง วิดเจ็ตใช้ App Group ในเครื่องเพื่อชื่อ ข้อความย่อ วันที่ สถานะ และภาพ เมื่อเปิดล็อกบันทึกจะซ่อนข้อความย่อ กิจกรรมสดอาจแสดงชื่อและเวลาบนจอล็อกกับ Dynamic Island ระวังผู้อื่นเห็นจอ

วันหยุดและเครือข่าย

อาจส่งประเทศ เขตย่อย และปีที่เลือกไปแคชสาธารณะ Firestore หรือ Nager.Date ผู้ให้บริการอาจรับ IP และบันทึกเทคนิค ไม่ส่งแผน บันทึก หรือ GPS ใช้สำเนาในเครื่องก่อน ข้อมูลอาจไม่ครบ

เว็บไซต์และอีเมล

เว็บไซต์คงที่ GitHub Pages ไม่มีโฆษณา สคริปต์วิเคราะห์ หรือคุกกี้ติดตามฝังอยู่ GitHub อาจประมวลผล IP เบราว์เซอร์ และบันทึกเข้าใช้กับความปลอดภัย ลิงก์ภายนอกและอีเมลมีนโยบายของตน ที่อยู่ ข้อความ และไฟล์ที่ส่งสนับสนุนใช้ตอบ ตรวจปัญหา และหน้าที่ตามกฎหมาย

วัตถุประสงค์และผู้ให้บริการ

ในเครื่องทำตามคำสั่ง เข้าสู่ระบบและสำรองให้บริการที่ขอ วิเคราะห์ตามตัวเลือกที่ถอนได้ โฆษณาตามกฎพื้นที่ ความปลอดภัย ป้องกันใช้ผิด และช่วยเหลือจำเป็นเพื่อผลประโยชน์อันชอบและหน้าที่ตามกฎหมาย ไม่ขายเนื้อหาแผน บันทึก หรือสำรองให้ผู้โฆษณาหรือใช้กำหนดเป้าหมาย Google, Apple, GitHub, Nager.Date และผู้ให้บริการอีเมลรับข้อมูลที่จำเป็นเมื่อใช้ฟังก์ชัน อาจเปิดเผยที่จำเป็นตามกฎหมายหรือคุ้มครองสิทธิ์

เก็บและลบ

เนื้อหาในเครื่องอยู่จนลบ ล้าง หรือถอนแอป สำเนาระบบขึ้นกับ iOS คลาวด์มักเก็บห้าเวอร์ชันล่าสุดที่สมบูรณ์จนแทนที่หรือลบบัญชี อัปโหลดไม่เสร็จถูกล้าง อาจเหลือเครื่องหมายลบขั้นต่ำที่เชื่อม ID เดิมเพื่อกันโทเคนที่ยังใช้ได้สร้างเนื้อหาใหม่ ไม่มีข้อความหรือข้อมูลติดต่อ วิเคราะห์ โฆษณา บันทึกระบบ และสำเนากู้คืนเป็นไปตามการตั้งค่า นโยบาย และกฎหมาย ไม่รับประกันลบทุกสำเนาทันที อีเมลเก็บจนแก้ปัญหาและติดตามที่จำเป็น ขอให้ลบได้เมื่อไม่ต้องใช้ คุณต้องลบไฟล์ส่งออกและสำเนาที่ส่งเอง

สิทธิ์และทางเลือก

แก้ ลบ ส่งออก ปิดวิเคราะห์ ปรับโฆษณา ถอนสิทธิ์ได้ การลบบัญชีในการตั้งค่าต้องยืนยันและลบคลาวด์ทั้งหมด แต่คงข้อมูลในเครื่องและส่งออก ขอเข้าถึง แก้ไข ลบ จำกัด สำเนา ถอนยินยอม คัดค้าน หรือร้องเรียนทางอีเมล เราตอบภายในเวลาตามกฎหมายและอาจตรวจตัวตน เคารพสิทธิ์เพิ่มเติมตามพื้นที่ เช่น ร้องเรียนหน่วยงานและปฏิเสธขาย／แบ่งปันเมื่อใช้บังคับ โดยไม่เลือกปฏิบัติ

ข้ามประเทศและความปลอดภัย

ผู้ให้บริการอาจประมวลผลนอกพื้นที่ ที่เก็บ การโอน และมาตรการขึ้นกับการตั้งค่า สัญญา และกฎหมาย ใช้ HTTPS สิทธิ์ตามบัญชีและตรวจสอบ แต่ไม่รับประกันปลอดภัยสมบูรณ์หรือเข้ารหัสทุกเนื้อหาแบบต้นทางถึงปลายทาง โปรดปกป้องบัญชีและสำรอง

เด็ก

Timo ไม่มุ่งเฉพาะเด็กอายุต่ำกว่า 13 และไม่ขออายุหรือข้อมูลเด็กเชิงรุก ต้องได้รับยินยอมผู้ปกครองก่อนใช้บริการออนไลน์เมื่อกฎหมายกำหนด แจ้งการประมวลผลไม่ได้รับอนุญาตเพื่อสืบสวน ลบ หรือดำเนินการจำเป็น
